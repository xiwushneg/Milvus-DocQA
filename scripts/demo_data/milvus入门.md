# Milvus 向量数据库入门

Milvus 是一款开源的高性能向量数据库，专为海量向量的相似度检索而设计，采用 Go 与 C++ 编写，支持水平扩展，可应用于图像检索、文本检索、推荐系统和对话式问答等场景。

## 部署形态

Milvus 提供三种部署形态。Milvus Lite 是轻量级版本，通过 pip 安装 pymilvus 即可使用，数据保存在单个本地文件中，适合原型验证和小规模数据。Milvus Standalone 是单机服务器版，通过 Docker 部署，支持更大规模的数据。Milvus Distributed 是分布式版本，可在 Kubernetes 集群上水平扩展至十亿级向量。

## 索引类型

Milvus 支持多种向量索引。FLAT 索引进行暴力检索，召回率百分之百，适合小数据集。IVF 系列索引通过聚类倒排加速检索。HNSW 是基于图的索引，兼顾高召回率与低延迟，是生产环境最常用的选择。AUTOINDEX 会根据数据规模自动选择合适的索引类型。

## 距离度量

常用的相似度度量包括三种。余弦相似度 COSINE 衡量向量方向的一致性，是文本向量检索最常用的度量。内积 IP 常用于推荐场景。欧氏距离 L2 衡量向量空间中的直线距离。
